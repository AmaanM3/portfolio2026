## Introduction

This week we continued working with React and learned more about how to build applications using multiple components. We focused on making our applications more interactive using props, useState and useEffect.

## What I Learned

We worked more with functional components and how to pass data between them using props. I also learned how useState works and how we can use it to update information on the page without refreshing it.

We also looked at useEffect, which can be used when fetching data from an API. Another topic was lists and keys, where we learned how to display multiple elements using the map function.

We also worked with forms, event handlers and how to manage state between components.
