## What I learned

This week we started working with frontend development after finishing the backend part of the semester. We started learning about JavaScript and the differences between Java and JavaScript.

I learned about variables, data types, arrow functions, arrays, DOM manipulation and event handling.

Later in the week we were introduced to React and Single Page Applications (SPA). We worked with Node.js, npm, Vite, JSX and functional components. I also learned about import, export, spread operators, destructuring, props and fetching data from an API.

## Exercises and Projects

During Tuesdays, I created a calculator and a Tic Tac Toe game using HTML, CSS and JavaScript. These exercises helped me understand how JavaScript works together with HTML and CSS to create interactive websites.

## Reflection

It was nice to start working with frontend after focusing on backend for most of the semester. Some of the JavaScript concepts were already familiar to me from Java, while others were new.

I still need more practice with React, but I now have a better understanding of the basics and how components work together.

I am looking forward to learning more about React and combining my frontend and backend knowledge during the upcoming weeks.
