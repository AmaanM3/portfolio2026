# Week 5 - SP-1 Movie Repository

In week 5 I worked on the SP-1 Movie Repository project together with my group. The project was about creating a backend application that gets Danish movie data from the TMDb API and stores it in a PostgreSQL database.

We worked with movies, actors, directors and genres and created entities and relationships between them using JPA and Hibernate. We also used DTOs for the data from the API and worked with DAO and service classes to keep the project more structured.

The application could search for movies, find movies by genre and show things like the highest rated, lowest rated and most popular movies. We also worked with JUnit and Testcontainers to test parts of the backend.

At the end of the project we made a small video where we presented the project and explained some of the code we had worked on.

Overall, this project helped me use many of the things we had learned in the previous weeks in one bigger backend project.
