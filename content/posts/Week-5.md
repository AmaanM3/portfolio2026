# Week 5 REST API

In week 5 I started working with REST APIs and learned how to create endpoints using Javalin.

I worked with the different HTTP methods GET, POST, PUT and DELETE and learned how they are used to get, create, update and delete data.

I also learned more about HTTP status codes and how an API should return the correct response when something works or when an error happens.

During the week I worked with a Dog API where I created different endpoints for dogs. I tested the endpoints by getting a dog by id, creating new dogs, updating dogs and deleting them.

Later in the week I worked on a Poem API where I connected the REST API to a PostgreSQL database using JPA and Hibernate.

I created a Poem entity and worked with the API setup, database configuration and error handling. I also added poems to the database and used the API to work with the stored data.

Overall, this week helped me understand how a REST API is structured and how it can communicate with a database.
