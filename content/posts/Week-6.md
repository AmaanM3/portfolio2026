# Week 6 REST Testing

In week 6 I worked more with REST APIs and learned how to test them automatically.

I worked with REST Assured and Hamcrest to test different endpoints. I tested things like GET, POST, PUT and DELETE requests and checked if the API returned the correct status codes and data.

I also made tests where I checked values inside the response body. This was useful because instead of testing every endpoint manually, I could run the tests and quickly see if everything was working.

I also worked with WebSockets and learned how they can be used for real time communication between a server and multiple clients.

Overall, this week helped me understand REST API testing better and also gave me a basic introduction to WebSockets.
