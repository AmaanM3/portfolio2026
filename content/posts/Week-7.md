## Week 7 - Security

This week, we focused on security in REST APIs and how to protect applications from unauthorized access. We learned about password hashing using BCrypt, authentication, authorization, and JSON Web Tokens (JWT).

We started by learning how to securely store passwords using BCrypt instead of plain text. We also worked with creating a security layer to manage users and roles.

During Wednesday's CodeLab, I worked on implementing security in a Hotel API using Java, Javalin, Hibernate, and PostgreSQL. We created User and Role entities and worked with authentication and database relationships.

On Thursday, we focused on JWT and how tokens are used to authenticate users and protect API endpoints.

I also worked on implementing BCrypt password hashing and JWT authentication in our group project, **DriveApp**, which is our biggest project this semester. DriveApp is a driving school management application, and adding security is an important step in making the application more secure.

GitHub: [DriveApp](https://github.com/Musa-909/DriveApp)

Overall this week helped me understand how backend security works in practice and how to implement authentication and password protection in a real project.
