## What I learned this week

This week we learned about deployment, Docker, Docker Hub, GitHub Actions and CI/CD. We also worked with Dockerfile and Docker Compose.

I learned how Docker works and how we can use it to run our applications in containers. We also learned how GitHub Actions can help automate the process instead of doing everything manually.

## What I worked on

This week I continued working on our semester project [DriveApp](https://github.com/Musa-909/DriveApp).

I used my DigitalOcean Droplet, where I already have our PostgreSQL database running. I installed Docker and Docker Compose and added swap memory because my server only has 512 MB RAM.

I also prepared the server for deployment and created a Docker Compose file. We worked with Maven to build our Java application into a JAR file and learned how to use GitHub Actions together with Docker Hub.

The application is not deployed yet, but the server is ready for it.

## Reflection

This week I learned more about how to get an application running on a server instead of only running it locally.

We are now done with all the backend topics for this semester, and I feel like I have learned a lot from working on DriveApp throughout the semester.
